01 / Challenge

Compliance at transaction speed

The challenge explored how AI could support financial-compliance workflows involving both transaction monitoring and corroboration of supporting documents.

02 / Solution

One workflow, multiple signals

The team developed AI-driven prototypes for real-time AML monitoring and document or image corroboration, bringing outputs together through a compliance-oriented workflow.

03 / Build

Measured, not just demonstrated

The prototype used Python, Flask, OCR and LLM workflows. We evaluated throughput, detection performance, API latency and LLM response time.

04 / Result

Performance under practical constraints

Prototype testing processed more than 1,001 transactions per hour with over 97% detection accuracy and sub-100 ms API latency. Typical LLM responses completed within two to four seconds.

05 / Perspective

AI has to fit the workflow

The project reinforced that an AI feature becomes useful when its outputs fit the user's workflow and its performance can be tested against meaningful operational requirements.
