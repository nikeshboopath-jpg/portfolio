Independent ML / Data Build

Guest Feedback Intelligence

A Python and Streamlit application for cleaning guest-feedback data, classifying sentiment and surfacing recurring themes while deliberately testing model failure cases.
NLPSentiment classification
StreamlitInteractive app
01 / Problem

Feedback is useful only when it can be interpreted

Raw guest comments contain inconsistent formatting, invalid values and language that simple keyword approaches can misunderstand.

02 / Pipeline

Clean before classifying

The application cleans CSV data, handles invalid dates and ratings, then applies text processing before presenting sentiment and recurring themes.

03 / Model

A practical baseline

The sentiment workflow used TF-IDF features with logistic regression, alongside keyword-based theme extraction and an interactive Streamlit interface.

04 / Evaluation

Failure cases matter

I deliberately tested ambiguous language, including phrases such as 'staff were not rude at all', and observed cases where the model produced the wrong sentiment. That made model limitations part of the analysis rather than something to hide.

05 / Takeaway

A metric is not the whole product

The exercise reinforced that useful ML work includes data quality, model behaviour, edge cases and communicating limitations—not simply training a classifier.
