RoundInvest

A micro-investing product concept designed around automated round-ups, configurable allocation rules and clear portfolio feedback.
Round-upsAutomated saving
Real-timePortfolio analytics
01 / Problem

Investing can feel too large to start

The product concept explored how everyday transactions could become a lower-friction entry point into saving and investing.

02 / Product

Turn spare change into a system

RoundInvest uses transaction round-ups, configurable allocation rules and portfolio analytics to make the investing flow easier to understand and control.

03 / Build

Product logic plus technical delivery

The project combined banking API concepts, backend services, automation, allocation logic and data visualisation rather than treating the idea as a static interface.

04 / Focus

Accessibility and control

The design emphasised adjustable controls and visible analytics so users could understand what the automation was doing rather than treating investing as a black box.

05 / Takeaway

Technology follows the user problem

The project strengthened my interest in product work: defining the behaviour first, then using APIs, automation and data to support it.
